# ShowTime V15 源码结构与构建

## 目录与模块

本包仅保留 V15 入口的递归依赖以及 V15 自检/硬件检查模块。旧版独立界面、入口、说明和打包配置均不包含。V15 需要的共用模块采用不带历史版本号的名称，内部协议标识及数据兼容字符串保持原样，不代表附带其他版本程序。

| 文件/模块 | 作用 |
|---|---|
| viewer.py、bootstrap_v15.py | V15 启动入口、启动日志与异常处理 |
| viewer_v15.py | 主窗口、设备选择、采集状态、显示及标定页面集成 |
| capture_devices.py、device_connection_v15.py | 采集格式与设备连接确认 |
| video_control.py、session_control.py | 采集启停状态机 |
| video_pipeline.py、video_protocol.py | 图像处理队列、类型与元信息解析 |
| frame_type_protocol.py、frame_diagnostics.py | 图像类型标记与异常诊断 |
| board_status.py | 板端状态解析 |
| calibration_dialog_v15.py、calibration_ui_v15.py | 标定页面及手动参数输入 |
| calibration_dialog_base.py、calibration_engine_base.py | V15 标定功能使用的共用实现 |
| calibration_engine_v15.py、calibration_validation_v15.py | V15 标定扩展与参数检查 |
| calibration_math.py、calibration_protocol.py、calibration_upload.py | 数学、参数编码及上传状态机 |
| pan_control_v15.py、pan_math_v15.py | 转向命令确认及可用范围检查 |
| selftest_v15.py | 无硬件离线自检 |
| hardware_check_v15.py | 实板检查工具，会使用设备；本次未执行 |
| ShowTimeV15_Portable.spec、build_portable.ps1 | V15 单文件 EXE 构建 |

程序图像、控制、标定算法未重写。本次仅规范必要模块的文件名/导入、补齐 V15 启动与打包配置；规范化导入名称后的 AST 比较用于确认原逻辑未变。已交付 EXE 是原 V15 程序逐字节复制，并非本次重新编译生成。

## 开发环境

现有 EXE 对应 Python 3.13.12（Windows x64）、PySide6 6.11.2、NumPy 2.5.2、opencv-python-headless 4.13.0.92、PyInstaller 6.22.2。版本依据原包 `runtime_versions.json`，安装清单已固定。串口使用 QtSerialPort，无需额外安装 pyserial。

普通使用者只需运行 EXE。以下命令供源码开发者在 PowerShell 中操作，先将当前目录切换到本包的“源码”目录：

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe viewer.py
```

## 离线自检

```powershell
.\.venv\Scripts\python.exe bootstrap_v15.py --self-test --report ..\source_selftest.json
```

自检验证参数编解码、转向协议、未连接设备时的界面门控、手动参数编辑及依赖加载。它使用离屏 Qt，不打开串口、采集卡或 EEPROM。自检不替代实板验收。

## 生成独立 EXE

```powershell
.\build_portable.ps1 -Python .\.venv\Scripts\python.exe
```

默认输出到本包的 `构建输出/release/ShowTimeV15_Portable.exe`，不会覆盖随包提供的原 EXE。可用 `-OutputDirectory` 指定输出目录。首次安装依赖需要网络；构建需提前装好 Windows x64 Python 与对应依赖。脚本使用本目录 spec，路径由脚本位置计算，不依赖原来的 F 盘工程。

分发时一并保留源码、第三方声明和 licenses。本包仅提供 V15 上位机源码，不包含 FPGA RTL、位流或板卡驱动。
