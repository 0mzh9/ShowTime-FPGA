# ShowTime V15 使用说明

## 1. 启动与连接

在 Windows 64 位电脑上双击 `ShowTimeV15_Portable.exe`。便携程序已带 Python、Qt、NumPy、OpenCV 运行库，无需另装 Python。设备驱动不包含在本包中。

1. 连接板卡 USB-UART、摄像头、HDMI 和 USB 采集卡，确认板卡运行兼容固件。
2. 选择实际板卡串口及 HDMI USB 采集设备；不要误选蓝牙串口或电脑内置摄像头。
3. 完成连接验证，界面显示设备就绪后再操作下方功能。
4. 点击“720P 裁剪图像”或“1080P 完整图像”开始采集；点击“结束采集”停止。

串口为 115200 波特率、8 数据位、无校验、1 停止位。采集卡须支持所选 1280×720 或 1920×1080 尺寸的 60 fps 模式，程序不会自动降低分辨率代替。连接验证失败时先检查设备选择、串口占用及固件协议兼容性。

## 2. 图像显示、保存与延时

- 可选择左右对比、仅原图、仅矫正图；视频卡片的全屏按钮及 F11 可进入整个屏幕显示，Esc 返回。
- Ctrl+S 保存两类图像，Ctrl+Shift+S 更改保存目录，F5 刷新设备。
- HDMI 原图与矫正图交替传输，两类画面的统计帧率分别计算，不应把单类约 30 fps 误认为 HDMI 只有 30 fps。
- 1080P 是 FPGA 输出画布规格，不能等同于摄像头原始有效数据原生达到 1920×1080。当前上位机对 1080P 原图分支提取中央 1280×720 区域；矫正分支按对应完整输出显示。
- 实时视频没有在 PC 上额外做去噪、锐化、Gamma 或畸变矫正。上位机执行采集格式转换、类型/状态解析、分流、上述原图区域提取及显示缩放。窗口缩放不表示传入像素变多。
- 底部总延时可点击查看分项。它组合 FPGA 处理耗时、主机处理、队列与预览等待等已测分项，不是包含曝光、采集卡和显示器扫描的严格端到端延时；无有效测量时不应当作 0 ms。

## 3. Gamma 与 720P 水平转向

Gamma 按钮通过串口请求 FPGA 开关，收到确认才更新已生效状态；处理在 FPGA 上完成。720P 模式且镜头参数有效时，可输入角度、左右步进或恢复 0°。上位机检查可采样范围后发送转向指令，FPGA 在帧边界切换并确认。1080P 不提供虚拟转向；角度不写 EEPROM，重新启动采集恢复 0°。

## 4. 标定、手动参数与 EEPROM

“生成矫正系数”在主界面打开标定页。生成参数是本机离线计算，打开页面和计算本身不等于向 FPGA 发送停机写入指令。

自动标定：导入实际 1280×720 模式下拍摄的原始棋盘格照片，填写内角点列数、行数及方格边长，再检测并生成参数。内角点数量不是黑白方格数量。导入目录存在 `original_left.png` 时优先使用这些原图；无效图片会在结果表显示原因，原文件不删除。应使用多个位置、距离及倾斜角度，检查重投影误差和边缘效果后再写入。

手动输入的八个参数：

| 参数 | 含义 |
|---|---|
| fx、fy | 横纵方向焦距，以像素为单位；必须为有效正值 |
| cx、cy | 主点在 1280×720 原图中的横纵坐标，以像素为单位 |
| k1、k2 | 径向畸变系数 |
| p1、p2 | 切向畸变系数 |

本版采用普通 Brown4 模型。鱼眼模型的 k3、k4 不能填写到 p1、p2。可从 FPGA 当前参数填入后修改，或查看当前系数。修改后必须重新“验证手动参数”，通过后才可写入。格式与范围验证不等于证明实际光学标定准确。

若要去除镜头畸变补偿，保留合理内参，令 k1、k2、p1、p2 为 0；不能把 fx、fy 也清零。720P 转向和输出视野仍由其对应映射决定，因此零畸变系数不等同于逐像素直通。

点击“输入矫正系数到 FPGA”才进入停止图像、上传、EEPROM 写入和确认流程。等待界面报告成功后再按提示恢复采集；上传期间不要断电。未发送新参数时，FPGA 使用已有有效 EEPROM 参数；初始或无效存储的回退行为由配套 FPGA 固件负责。

## 5. 数据位置与常见问题

数据默认写入 EXE 旁的 `data`，无权限时回退到 `%LOCALAPPDATA%/ShowTimeV15`。本整理包不带历史截图、标定结果或日志。首次启动可能读取这台电脑已经保存的窗口/设备偏好，这些本机设置并非包内携带。

- 连接失败或按钮灰色：检查串口/采集设备、固件兼容性，关闭占用设备的其他程序，再重新验证。
- 提示不支持格式：在系统中确认采集卡枚举了所选尺寸 60 fps 模式。
- 参数验证失败：确认填写全部八项、内参对应原图尺寸，并查看页面给出的拒绝原因。
- 启动失败：查看 `data/logs` 中日志及 `runtime_versions.json`；本包的离线自检结果在“验证记录”。

本次整理只做离线验证，没有重新进行实板、断电或异机测试。
