## 数据来源

本页依据随仓库发布的技术报告第 3.3 节（PDF 第 27–29 页）。图片按报告图号提取，未修改画面内容。资料整理不等于对当前工程重新进行全流程编译或实板复测。

## 几何与清晰度

- 直线度：原图与矫正图中对应的左侧棋盘区域，按棋盘行列直线拟合残差评估；720P / 1080P 相对 RMS 偏差分别降低 51.1% / 63.5%。该结果不能直接推广为全视场误差。
- MTF50：水平、垂直各取 3 段斜边，以各方向中位数统计。矫正后 720P 为 0.209 / 0.169，1080P 为 0.250 / 0.218 cycles/pixel。属于图像域初测。
- 输入始终为 1280×720；1080P 是输出画布尺寸。

## 帧率与长测

- HDMI 总刷新率 60 Hz，原图/矫正图逐帧交替；每类约 30 fps。
- 两种模式各运行 1800 秒，矫正图平均帧率为 29.99498 / 29.99752 fps。
- 稳定阶段新增尺寸、标记、状态、空帧异常为 0；队列旧帧分别丢弃 11 / 6 帧，最大排队 2 帧。不能据此宣称零丢帧。
- 59 次转向确认成功；成功应答与目标矫正帧的 HDMI 输出关联。

## 延迟

- 46.2 ms 为既有上位机记录中的平均统计值，组成项含 FPGA 帧处理、PC 转换解析及等待；各项尚未严格绑定同一帧，不是曝光到屏幕的端到端测量。
- 208 ns = 26 / 125 MHz，仅指坐标流水在无停顿条件下的延迟，不包含帧缓存、DDR 与显示等待。
